# 🚀 Quick Start Guide

Welcome to your Indian Tadka Restaurant Menu app!

## ⚡ Start Development Server

Open your terminal in this directory and run:

```bash
npm run dev
```

The app will automatically open at: **http://localhost:3001**

## 📝 First Steps

### 1. **Customize Restaurant Info**
Edit `src/data/menu.json` to update:
- Restaurant name, phone, email
- Address and operating hours
- Social media links

### 2. **Update Menu Items**
In the same `menu.json` file:
- Add/remove menu items
- Update prices and descriptions
- Set dietary information
- Mark popular items

### 3. **Test Mobile View**
- Press F12 in your browser
- Click the mobile device icon
- Test the floating call button

## 🎨 Customization

- **Colors**: Edit `tailwind.config.js`
- **Fonts**: Update `src/index.css`
- **Layout**: Modify components in `src/components/`

## 📱 Key Features to Test

1. **Responsive Design**: Resize browser window
2. **Menu Filtering**: Click category buttons
3. **Mobile Navigation**: Test hamburger menu
4. **Call Buttons**: Multiple call-to-action buttons
5. **Floating Button**: Appears when scrolling
6. **Smooth Scrolling**: Click navigation links
